# hgsDevv | Portfólio

Portfólio de **Higor Gonçalves dos Santos**. **hgsDevv** é o seu projeto pessoal de desenvolvimento web.
Visual moderno com toques retrô inspirados no Super Nintendo, feito com HTML, CSS e JavaScript puro.

## Estrutura

```
hgsdevv-portfolio/
├── index.html      # página principal
├── css/style.css   # estilos (cores no topo, em :root)
├── js/main.js      # interações (tema, animações ao rolar, editor de código)
├── js/snake.js     # Pixel, a cobrinha mascote (jogo Snake)
└── assets/img/     # foto de perfil e imagens dos projetos
```

## Como rodar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Detalhes

- `SELECT` alterna entre tema claro e escuro
- Clique na faixa da cobrinha para soltar uma maçã
- ↑ ↑ ↓ ↓ ← → ← → B A esconde uma surpresa 😉
